House rules

05 / spec

Standards I apply on every theme build so the codebase stays consistent, predictable, and easy for another developer — or a future me — to pick up.

NAMING
Consistent, collision-free class names across the whole theme — BEM-style naming kept scoped per section.
LOCALE
Themes ready for translation from day one — strings routed through Shopify's t: translation keys in schema.
METAFIELDS
Content modeled with Metafields and Metaobjects where it belongs, so merchants edit data — not markup — in the theme editor.
BREAKPOINTS
Responsive, mobile-first layouts, tested for real cross-browser and cross-device compatibility, not just one viewport.
EDITOR-SAFE
Sections and blocks built to survive the theme editor — no broken states when merchants reorder or duplicate.
PERFORMANCE
Every build checked against load time, accessibility, and organic SEO basics before it ships — not bolted on after.
